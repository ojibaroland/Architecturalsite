Save & Publish

Apply your changes

Preview applies changes in this browser only, so you can check the site first. Publish commits them to GitHub so the live site updates for everyone.

Create the token at GitHub → Settings → Developer settings → Fine-grained tokens. Give it access to only this repository with Contents: Read and write permission, and set an expiry. It is stored in this browser's local storage only.
